# PUBG Mobile 团队竞技（Team Deathmatch）规则记录

> 记录日期：2026-10-24
> 范围：PUBG Mobile（国际服）为主，附《和平精英》差异说明
> 说明：标注「待核实」的条目尚未在官方来源中确认，以当前客户端实际表现为准

## 1. 模式定位

- **4v4** 竞技场（Arena）模式，快节奏、无限复活、纯枪法对抗
- **无搜刮、无载具、无蓝圈、无药品与防具拾取**
- 入口：
  - PUBG Mobile：模式选择 → **Arena / 竞技场** → Team Deathmatch
  - 和平精英：创意工坊 → 竞技 → **团队竞技**（同分类下还有占点竞技、军备团竞）
- 单局时长约 **10 分钟**

## 2. 胜负条件

| 条件 | 结果 |
| --- | --- |
| 一方团队击杀数先达到 **40** | 该队获胜 |
| 10 分钟结束仍未到 40 | 击杀数多的一方获胜 |
| 双方击杀数相同 | 待核实（是否加时/平局） |

- 计分只看**团队总击杀数**，个人数据不单独决定胜负
- 助攻是否计入团队分数：待核实

## 4. 出生、复活与生存机制

- **无限复活**：阵亡后在出生点重生，重生后短暂无敌（时间待核实）
- **初始装备**：出生自带 **2 级头盔 + 2 级防弹衣**；防具耐久不会自动恢复，但每次复活会重新刷新
- **无药品**：不能拾取/携带医疗品；一段时间未受到伤害后，血量自动回复至 100
- **配装**：
  - 《和平精英》经典仓库：出生点摆放枪械桌与配件桌，开局有数秒时间选枪、装配件
  - PUBG Mobile：通过 **Tactical Supplies（战术补给）** 更换枪械；配装槽位随 **Survivor Level（生存等级）** 提升解锁
  - 部分版本支持在对局内回到出生点更换配装，复活时生效
- 弹药是否为无限/固定量：待核实
- 投掷物是否可用：待核实（不同版本差异较大）

## 5. 配装与武器（经典仓库图）

《和平精英》早期仓库图的武器布置：

- 一侧桌面：**AKM、M762、98K、S12K**
- 另一侧桌面：**M249、M416、UZI**
- 中间桌面：全枪械配件
- 每把枪自带**快速扩容弹匣**，瞄具只有**红点**与**4 倍镜**可选

> 后续版本有增删（如 2026 赛季仓库图移除 S686/S1897 等霰弹枪、调整狙击枪位），以当前端内配装界面为准。

## 6. 视角

- 支持 **TPP（第三人称）与 FPP（第一人称）** 两种视角
- 《和平精英》团竞上线初期仅限第一人称，后续版本开放第三人称选择

## 7. 奖励与成长

- 结算给予经验/任务进度类奖励
- 是否影响经典模式排位分：**不影响**（团竞独立结算）
- 《和平精英》已上线独立的**团竞排位赛季**（如 2026-10 的 VS.1 赛季）；PUBG Mobile 国际服是否有对应排位：待核实

## 8. 与端游 TDM 的区别

| 维度 | 手游团竞 | 端游 TDM |
| --- | --- | --- |
| 人数 | 4v4 | 8v8 |
| 结构 | 单局定胜负 | 回合制，先赢 2 回合 |
| 击杀目标 | 40（10 分钟） | 40 / 回合（10 分钟） |
| 视角 | TPP + FPP | 以 FPP 为主 |
| 地图 | 仓库、遗迹等小图 | 从大地图切出的 7 块战场 |
| 定位 | 练枪/热身，独立结算 | 街机模式，给 BP |
