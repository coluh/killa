# 战斗数值（PUBG Mobile 参考）

> 参考：PUBG.co.za 的社区测量（Patch 4.5）与 PUBG Mobile TDM 规则。
> 社区数据可能与官方最新版本有差异，调参时以体感为准。

## 目标模型

- 生命值：100
- 出生装备：2 级头盔 + 2 级防弹衣（本作耐久 200，复活重置）
- 2 级护甲减伤：**40%**，只作用于被覆盖部位（头/躯干）
- 命中部位：头 / 躯干（本作没有四肢独立判定）
- 自动回血：脱战 5 秒后，以 20 HP/s 回复

## 机器人

- 反应 0.6–1.2s
- 瞄准误差 0.05–0.12 rad（约 3–7°）
- 子弹扩散 ×2.5
- 点射间隔 320–480ms，停火 0.6–1.2s
- 交战距离 20m，近距离会后退保持距离
- 数值与玩家相同，通过精度/反应而非减伤来降低威胁

## 调参入口

- `server/internal/game/config.go`：速度、护甲、回血
- `server/internal/game/weapons.go`：武器表
- `server/internal/game/bot.go`：机器人反应/误差/节奏
